# student-data-collections — منصة جمع بيانات مدارس المجد الأهلية

واجهة ثابتة (GitHub Pages) + خادم Google Apps Script مرتبط بـ Google Sheet.
كلمات المرور تُفحص في الخادم فقط، والمرحلة تُحدَّد من الجلسة، فلا يمكن لمستخدم الكتابة في ورقة مستخدم آخر.

## خطوات التشغيل
1. أنشئ Google Sheet جديداً ← الإضافات ← Apps Script، والصق محتوى `apps-script/Code.gs` واحفظ.
2. شغّل الدالة `setupAll` (وامنحها الصلاحيات). تُنشأ ورقة «المستخدمون» وورقة لكل مرحلة (15) و«لوحة المتابعة».
3. من ورقة «المستخدمون» عدّل اسم المستخدم وكلمة المرور لكل مرحلة (التغيير فوري، ويُنهي جلسات المستخدم القديمة).
   عمود «مفعّل» يوقف المرحلة، وعمود «مفتوح للتعديل» يقفل الإدخال بعد الاعتماد.
4. نشر ← نشر كتطبيق ويب: التنفيذ باسمي، الوصول: أي شخص. انسخ الرابط إلى `config.js`.
5. ارفع المشروع إلى GitHub وفعّل Pages (Settings ← Pages ← main / root).

```bash
git remote add origin https://github.com/<حسابك>/student-data-collections.git
git push -u origin main
```
> لا تشارك الشيت نفسه مع مستخدمي المراحل؛ ورقة «المستخدمون» تحوي كلمات المرور.

## المعاينة والمعلمون
- بعد الدخول تظهر صفحة اختيار: بيانات الطلاب أو بيانات المعلمين (ورقة مستقلة «معلمو …» لكل مرحلة، مع رفع Excel ونموذج للتنزيل).
- للمعاينة بدون خادم: اجعل `config.js` يحوي `const APPS_SCRIPT_URL = 'DEMO';` ثم ادخل بـ demo / demo (لا تُحفظ البيانات).
- بعد تحديث `Code.gs` في Apps Script شغّل `setupAll` مرة أخرى ثم انشر نسخة جديدة (Manage deployments ← Edit ← New version).

## تصدير ملفات المراحل
من قائمة «مدارس المجد» في الشيت اختر «تصدير كل مرحلة كملف مستقل» لإنشاء ملف Google Sheet لكل مرحلة في مجلد داخل Drive.

## حساب الإدارة
يُنشأ صف `admin` في ورقة «المستخدمون» عند تشغيل `setupAll` (عدّل اسمه وكلمته). من صفحة الدخول اضغط «دخول الإدارة» لعرض تحليل كل المجمعات بفلاتر (المجمع/المرحلة/الصف/نوع التعليم) بحسب الطلاب أو الفصول، مع المعلمين حسب التخصص وتصدير Excel. الحساب للقراءة فقط.
